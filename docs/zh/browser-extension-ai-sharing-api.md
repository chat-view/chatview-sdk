# 浏览器扩展 AI 对话分享 API

扩展开发者通过 **browser extension API for AI conversation sharing** 将 DOM 中的 `innerHTML` POST 到 `https://chat-view.com/api/contents`。Token 应保存在 `chrome.storage.local`，不要写进公开仓库。

参考示例：[browser-extension-share-chatgpt-conversation.js](../../examples/javascript/browser-extension-share-chatgpt-conversation.js)
